⚠️ Exact Multicollinearity Diagnosis & Feature Resolution (全共線性診斷與排除)

原始 King County 資料集包含 17 個候選特徵，其中包含 sqft_living (總居住坪數)、sqft_above (地上坪數) 與 sqft_basement (地下室坪數)。
嚴謹數學驗證：sqft_living = sqft_above + sqft_basement (21,613 筆樣本無一例外，為完全線性恆等式)。
此全線性相依將導致特徵矩陣秩虧（Rank-Deficient，行列式值為 0），VIF 膨脹至無窮大（數值運算無法唯一求得反矩陣）。
依專案標準規範，在基準多元線性迴歸模型中移除 sqft_basement，保留 16 個滿秩特徵；同時完整保留 17 個特徵以供探索性分析與迴歸診斷對比驗證。

Methodological Distinction: Statistical Inference vs. Predictive Modeling

🔬 Statistical Inference Within-Sample Explanatory
  • Objective: Quantify relationships, test scientific hypotheses (e.g., H₀: βⱼ = 0), and understand underlying mechanisms.
  • Core Metrics: Standard errors, t-statistics, p-values, 95% confidence intervals, and Adjusted R².
  • Assumptions: Relies on Gauss-Markov assumptions (Linearity, Independence, Homoscedasticity, Normality).
  • Focus: Unbiased parameter estimation on observed data.
🎯 Predictive Machine Learning Out-of-Sample Generalization
  • Objective: Maximize accuracy and minimize prediction error on previously unseen observations.
  • Core Metrics: Held-out Test RMSE, Test MAE, Out-of-sample R², and cross-validation loss.
  • Tradeoff: Embraces the Bias-Variance Tradeoff (accepts slight coefficient bias to reduce variance).
  • Focus: Generalization capability verified on an isolated holdout test set.
⚠️ Critical Limitation: Post-Selection Inference Caution: Standard OLS hypothesis tests and p-values assume that the model structure was specified a priori before looking at the dataset. When the model is chosen data-dependently via 20 feature-selection algorithms, the nominal p-values become overly optimistic (selection bias / "data snooping"). The standard errors underestimate true uncertainty. Therefore, the held-out test evaluation (Test RMSE 8,243) is the authentic test of predictive validity, while the p-values should be interpreted as exploratory ranking diagnostics rather than confirmatory proofs.
